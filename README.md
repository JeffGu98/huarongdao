# 数字华容道

5×5 数字滑动拼图，用 Godot 4.7 写成。

照片上的开局是 23 和 24 对调、空格在右下角。这个排列的逆序数是奇数，靠滑动还原不了。点「随机开局」会从终态合法地打乱 100 步，那一局一定能还原。

判定和步骤说明在 `还原步骤.md`。

## 安卓安装

在 [Releases](https://github.com/JeffGu98/huarongdao/releases) 下载 `huarongdao-1.0.2.apk`。安装前允许这个来源的应用。界面按竖屏排，棋盘按屏幕宽度铺开。

点数字，或用方向键移动空格。红边是还没归位的块。随机开局后点「自动还原」，会把这一局演示滑回终态。浅局走最短步数，随机开局只保证能还原，不保证最少步。

## 本地运行

需要 Godot 4.7.2。

```bash
godot --path .
```

无界面自测：

```bash
godot --headless --path . -s res://selftest.gd
```
